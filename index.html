A FunSearch / AlphaEvolve-style experiment: 12 LLMs on a university GPU cluster were made to write, execute, and iteratively improve real algorithms — scoring correctness and performance by actually running the code.

The loop

Each model starts from a blank prompt. Every generation it receives the task spec, the surviving parent programs with their measured fitness, per-trace score breakdowns, and the exact errors of failed children. It writes a new candidate; the candidate runs in a subprocess sandbox against fixed workloads; the score feeds the next generation. Slow reasoning models evolved parallel islands. No human wrote any algorithm — only the fitness function.

Task 1 — Evolve an online cache eviction policy

Candidates implement evict(cache, meta) → index, called on every miss of a 50-entry cache over five fixed 20,000-request traces: Zipf, drifting-Zipf, scan+hot-set, cyclic-loop-with-bursts, and a scan-heavy LRU-killer. Fitness = mean hit rate. The meta dictionary deliberately exposes raw materials (frequencies, last-access times, a 64-key recent window) but no ground truth about the future.

What the winner actually invented

DeepSeek V4.1 Flash — 0.6443 (+48% over LRU) converged on a trace-shape classifier: it computes a uniqueness ratio and burst statistics over the recent window, detects "scan-like" vs "cyclic-like" vs "hot-set" regimes, and switches between frequency-weighted LRU, MRU-among-cold (anti-loop-thrash), and burst-protected eviction. An Adaptive Replacement Policy, discovered by iteration.

# soclaas_x-test-2 | cache | fitness 0.6443
import math
import random


def evict(cache, meta):
    if not cache:
        return 0

    n = len(cache)
    time = meta.get("time", 0)
    cache_freq = meta.get("cache_freq", {})
    cache_last = meta.get("cache_last", {})
    recent = meta.get("recent", [])
    capacity = meta.get("capacity", n)

    recent_count = {}
    for k in recent:
        recent_count[k] = recent_count.get(k, 0) + 1

    L = len(recent)
    uniq = len(recent_count)
    uniq_ratio = (uniq / L) if L else 0.0
    max_r = max(recent_count.values()) if recent_count else 0

    freqs = [cache_freq.get(k, 0) for k in cache]
    lasts = [cache_last.get(k, -1) for k in cache]

    min_f = min(freqs) if freqs else 0
    max_f = max(freqs) if freqs else 0

    def mru_among(indices):
        best_i = indices[0]
        best_last = lasts[best_i]

GLM 5.3 Flash — 0.6206 took a different route: a poor-man's Belady. Per key it remembers the last 3 inter-arrival gaps, predicts the next access time, evicts the key predicted to return furthest away; keys seen once are treated as never-returning (scan resistance), and keys overdue vs their own prediction fall back to LRU.

# soclaas_x-test-1 | cache | fitness 0.62058
import math
import random

# --- tunable constants (targets for future generations) ---
_TAU = 800.0   # recency decay time constant, in requests (~16 * capacity)
_BAND = 2.0    # near-tie band: evict randomly among keys scoring within
               # _BAND * min_score  (randomization dodges LRU's cyclic pathology)


def evict(cache, meta):
    """Return index in `cache` of the item to evict on a miss.

    Policy: minimum time-decayed frequency
        score = freq * exp(-age / tau),  age = time - last_access
    with randomized tie-breaking inside a near-tie band.
    """
    n = len(cache)
    if n <= 1:
        return 0

    t = meta["time"]
    freq = meta.get("cache_freq") or {}
    last = meta.get("cache_last") or {}

    scores = []
    for k in cache:
        f = freq.get(k, 1)
        if f < 1:
            f = 1
        age = t - last.get(k, t)
        if age < 0:
            age = 0
        scores.append(f * math.exp(-age / _TAU))

Candidates implement pack(items, capacity); score = mean bins used ÷ L1 lower bound over 16 instances (uniform, small-size sets, mid-size, mixed). Lower is better; First-Fit-Decreasing scores 1.0853 on these instances.

The plateau. Every model that produced valid code — from Llama 8B to DeepSeek V4.1 — converged to exactly the FFD reference, with identical per-instance score vectors. Single-shot ordering heuristics saturate at FFD; breaking below it requires embedding local search inside the candidate within the time budget, which no model found in 20 generations. Meanwhile Llama 3.1 8B — the only model that never hit the attractor — finished worse (1.1189) but was still learning when its budget ended.

Lesson: the shape of the fitness landscape decides how much room evolution has. Online caching, with its adversarial, non-stationary structure, rewards invention; classic deterministic heuristics have a hard attractor at the textbook algorithm.

Two failure modes mattered as much as raw ability: budget discipline (Qwen 3.5 never emitted a single runnable program in 50 tries, even with format remediation) and reliability (x-test-3 was down all day; Gemma 4's ollama backend collapsed under concurrent load). In an evolution loop, a model that can't reliably emit a complete, runnable artifact scores zero regardless of its intelligence.
